## 1. 设计语言

## 4. 实现要点与坑

1. **移动端输入框被压扁**：`.url-input` 桌面用 `flex: 1`，切到纵向 flex 后 `flex-basis: 0` 会覆盖 `height`，输入框只剩 16px（文字被裁）。修复：移动端显式 `flex: none; width: 100%; height: 50px`。
2. **SVG 里的 `fill="var(--ink)"` 在深色下不生效**会退回黑色；logo 方块在深色主题会隐形。实践中改用 `fill="var(--ink)"` 后实测可生效（Chromium），但仍建议关键图形用 `:style` 绑定，避免不同浏览器差异。
3. **奇数个清晰度按钮**会留下空格子（边框线断在中间）；用 `.fmt-chip:last-child:nth-child(odd) { grid-column: span 2 }` 铺满。
4. **vite 8 / rolldown 裁剪**：只出现在动态 `:class` 三元里的类会被当 unused 裁掉；本版所有状态类（`.active/.vip`）同时出现在模板静态位置或通过 `:style` 兜底，构建后需 grep 产物 CSS 验证。
5. 字体不引外链：使用系统 Helvetica/Arial 栈，避免 Google Fonts 在国内不可达。

## 8. 第二轮：字体、动效与内容扩充（2026-10-23 下午）

用户反馈"缺动效、字体不好看"，参考 claude.com/product/overview 的编辑气质做了第二轮。

### 8.1 字体（自托管，零外链）

| 用途 | 字体 | 文件 |
|---|---|---|
| 大标题（H1 / 区块标题 / 陈述 / CTA） | **Instrument Serif 400**（中文回退 Songti SC / STSong / SimSun） | `public/fonts/instrument-serif-latin.woff2`（21KB）+ italic（22KB，备用） |
| 正文 / UI / 小标题 | **Inter**（可变字重 100–900） | `public/fonts/inter-latin.woff2`（48KB） |

- 只取 **latin 子集**：体积从 300KB+ 降到 91KB；中文走系统字体，避免几 MB 的 CJK 字体
- 未使用 Google Fonts CDN（国内不可达），`@font-face` 写在 `style.css` 顶部，路径 `/fonts/*.woff2`
- 字号同步上调：H1 `clamp(46px, 7.8vw, 102px)`，区块标题 `clamp(32px, 3.9vw, 58px)`
- 小标题（功能卡、步骤、FAQ 问题）仍用 Inter 700——衬线只负责"大字号展示"，保证可读性

### 8.2 动效（无第三方库）

| 动效 | 实现 | 参数 |
|---|---|---|
| 滚动入场 | `v-reveal` 指令（`main.js`，共用一个 IntersectionObserver） | 上移 18px + 淡入，750ms，`cubic-bezier(.2,.65,.3,1)`；同组错峰 60–160ms |
| Hero 首屏 | 纯 CSS `@keyframes rise`，按 eyebrow → H1 → 副标 → 输入框 → 数据栏依次入场 | 延迟 0.05s → 0.63s |
| 导航进度 | 滚动时底部 2px 红条宽度 = 页面进度 | rAF 节流，0.1s 线性 |
| 平台跑马灯 | 渲染两份列表 + `translateX(-50%)` 无限循环 | 34s，hover 暂停 |
| 按钮箭头 | CTA 按钮 `→` hover 右移 4px | 280ms |
| 卡片 hover | 背景变为次级纸色、编号变红、示例卡上浮 2px | 220–350ms |
| FAQ | 展开内容 `fade-up` 350ms | — |

- **`prefers-reduced-motion: reduce` 全关**：指令直接显示、跑马灯 `animation: none`、全局动画时长归零
- **到底兜底**：滚到页面底部时把剩余未触发元素一次性显示，避免最后一块永远停在 `opacity: 0`

### 8.3 新增内容区块

1. **平台跑马灯**（Hero 下方）：PLATFORMS / 1000+ 标签 + 10 个平台名无缝滚动（品牌名不翻译）
2. **大字陈述**：`WHY / 2026` + 衬线巨字「不装软件，不登录，粘贴就能下。」+ 句末红方块
3. **三种方式对比表**（05）：网页版 / 浏览器插件 / 桌面客户端 × 免安装、手机可用、AI 总结、离线批量；网页版列用纸色底 + 红色 √ + 顶部红条强调
4. 区块编号随之调整为 03–08，CTA 改 09

新增 i18n key：`stmt.lines`、`stmt.sub`、`cmp.title/sub/h1-3/r1-4/legend`（6 语言各一套）。

### 8.4 本轮踩的坑

1. **两栏 grid 的 DOM 顺序**：陈述区把 label/标题/副文直接塞进 grid，导致大标题被放进 260px 右列（截图里竖排断字）。必须包一层 `.statement-main`。
2. **中文断行控制不住**：靠 `max-width` 调宽度会在「登 / 录」之间断开；改成 i18n 字符串里写 `\n` + `white-space: pre-line`，每种语言自己决定断行（日文因此是 3 行）。
3. **IntersectionObserver 的 rootMargin**：`-10%` 会让页面最底部的页脚永远无法触发（元素落在收缩后的视口外）；改为 `0px` + 到底兜底。
4. **移动端表头换行**：「极易下 · 网页版」在 390px 下折成两行，靠 `white-space: nowrap` + 字号 7.5px 解决。
