> **当前视觉规范以 `11-前端瑞士风格改版.md` 为准**，本文仅保留当时的决策过程与会员态修复记录。

## 1. 改版动机

- 支付/会员功能上线后，落地页内容密度不足：功能卖点只有 6 张小卡，访客无法在购买前理解「AI 总结」的产出形态
- 对标竞品 [bibigpt.co](https://bibigpt.co) 的落地页套路：数字统计带、功能演示、场景化文案、清晰的转化路径

## 2. 会员态体验修复（用户验收反馈）

| 问题 | 修复 |
|---|---|
| 导航栏会员标识不显眼、看不到剩余时间 | 用户区加金色描边 + 徽章内嵌闪电 SVG + 金色「剩 N 天」（向上取整，最少 1 天）；hover 显示精确到期日 |
| 已购会员后定价按钮仍显示「立即开通」 | 有效会员显示「续费会员」（`pricing.renew`，6 语言）；到期后由后端 `is_vip` 实时判定自动回退 |

> 教训：会员态是一组独立的 UI 状态，做功能时应通盘过一遍所有相关界面的按钮动词、身份标识与时间信息，而不是只把链路跑通。

## 4. 视觉决策

- **配色体系延续 Teal #0d9488 / 橙 #ea580c**，但职责分离：品牌色 = Teal（标题渐变、图标、高亮），**行动色 = 橙**（解析按钮、CTA 按钮）——转化按钮在深色底上对比最强
- **Hero 为深色锚点区**：`#052e29 → #073b33 → #0a1a28` 渐变 + 两个 blur 光斑 + 网格纹理（radial mask 渐隐）；浅色主题下同为深色，形成「深色开场 → 浅色正文 → 深色收尾」的节奏
- 玻璃输入卡：`rgba(255,255,255,.055)` + backdrop-blur + 细边框
- 设计系统工具（ui-ux-pro-max）建议蓝+玻璃拟态方向，最终决策保留 Teal 体系以维持品牌延续性与辨识度，仅吸收其「玻璃质感、CTA 对比、图标纪律」等要素

## 5. 内容真实性原则

统计带与示例卡**不使用无法验证的数字**（如「100万+ 用户」），全部采用可复现的产品事实：

- `1000+ 支持平台`（yt-dlp 引擎能力）、`4K 无水印`（实测）、`免费 AI 总结·每日 3 次`（真实配额）、`秒级解析`
- 示例卡明确标注「示例」，章节时间戳为示意排版，不冒充真实总结结果
- 与 SEO（docs/05）一致：页面陈述的事实必须与产品实际能力一致，llms.txt / 定义段 / FAQ 三处对齐
