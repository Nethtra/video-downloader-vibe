# 需求分析 — 极易下（万能视频下载网站）

> 文档版本：v1.0（2026-10-09）
> 状态：功能开发完成，已上线运营

## 1. 项目背景

很多同学有把视频保存到本地的需求，但直接从平台下载往往行不通：

- 平台不支持下载功能（如网页版抖音、小红书）
- 下载不够方便（不支持批量、有清晰度限制、需要装 App / 登录账号）
- 跨设备困难（手机保存的视频电脑拿不到，反之亦然）

因此希望做一个**万能视频下载网站**：粘贴链接即可快速下载，随时随地、多平台、手机可用。

## 2. 人工思考的三个前置问题（需求方的原始答案）

| 问题 | 需求方答案 | 落地结论 |
|------|-----------|---------|
| 前端界面要什么样？ | 尽量吸引人付费（突出实用价值） | 仿成熟产品 UI（codefather painting），定价引导区 + 模拟支付全流程 |
| 需要后端吗？ | 需要，但先不要数据库，尽量轻量 | FastAPI 单服务，任务状态存内存，文件落临时目录自动清理 |
| 怎么下载到视频？ | 站在巨人肩膀上，用开源项目，不自己承担风险 | 直接封装 yt-dlp（~5w star，支持 1000+ 平台） |

## 3. 目标用户与核心场景

**目标用户**：有保存视频需求的学生/普通网民，不想装软件、不想折腾。

**核心场景（User Story）**：

| # | 场景 | 验收标准 |
|---|------|---------|
| S1 | 在手机/电脑上粘贴视频链接 → 选清晰度 → 保存 | 全程 ≤3 步，无需注册登录 |
| S2 | 从抖音 App 复制分享口令（含短链/口令文本）粘贴 | 能自动识别并解析 |
| S3 | 只想要视频里的声音（课程/播客） | 可提取音频 |
| S4 | 用户觉得好用，想开通会员 | 定价页 → 收银台 → 支付成功闭环 |
| S5 | 手机浏览器打开网站使用 | 页面响应式，可正常下载 |

## 4. 功能需求（按优先级）

### P0（核心，必须）
- FR1 链接解析：输入链接（或含链接的口令文本），返回标题/封面/作者/时长/可选清晰度
- FR2 视频下载：选择清晰度后后台下载，实时进度反馈，完成后可保存到本地
- FR3 多平台支持：B站、抖音为基础盘，其余依赖 yt-dlp 生态（1000+ 平台）
- FR4 移动端适配：手机浏览器可完成完整下载流程

### P1（重要）
- FR5 仅音频提取（mp4 → m4a）
- FR6 会员定价展示 + 支付流程（先模拟支付，预留真实渠道接口）
- FR7 下载文件临时保管（30 分钟），超时自动清理，防止磁盘塞满

### P2（后续迭代）
- FR8 批量下载队列
- FR9 接入真实支付渠道（虎皮椒/蓝兔/微信商户号）
- FR10 会员权益真正生效（清晰度门禁、极速通道）

## 5. 非功能需求

| 维度 | 要求 | 现状 |
|------|------|------|
| 易用性 | 零学习成本，报错必须是可读中文 | ✅ 所有异常均有中文提示 |
| 轻量 | 无数据库、无消息队列，单端口单进程可跑 | ✅ 内存任务表 + 临时目录 |
| 安全 | 不收集用户信息、不需要用户提供任何 Cookie/凭证 | ✅ 抖音通道服务端自铸访客凭证 |
| 健壮 | 网络抖动可重试，任何异常不返回 500 裸错误 | ✅ 重试 + 三层异常兜底 |
| 合规 | 内容版权归平台及作者，仅供个人学习，页面明示免责声明 | ✅ 页脚声明 |
| 隐私 | 不记录用户下载历史（任务完成即弃） | ✅ 内存任务 30 分钟过期 |

## 6. 风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 平台风控升级（接口/签名变化） | 高 | 抖音走独立通道可单独热修；yt-dlp 社区持续更新，锁版本定期升级 |
| 服务器 IP 被平台风控（云部署） | 高 | 已知限制：本地/自有 VPS 部署不受影响；文档明示 |
| 用户下载版权内容用于传播 | 中 | 页脚免责声明；仅个人学习定位 |
| 大文件拖垮服务 | 中 | 并发上限 3，文件 30 分钟清理 |
| 支付合规 | 中 | 当前为模拟支付；接真实渠道前需完成主体资质 |

## 7. 明确不做的事（Scope Out）

- 不做用户系统（注册/登录）——保持零门槛
- 不做视频转码/剪辑——只做平台原始流的下载
- 不绕过付费内容/登录才能看的内容——只服务公开视频
- 不支持图集/图文内容（抖音）——明确报错提示，后续按需迭代
