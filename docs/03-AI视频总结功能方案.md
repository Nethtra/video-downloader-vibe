# 03 · AI 视频总结功能 · 方案与实现记录（最终版）

> 2026-10-09 立项，同日完成开发、多轮修复与上线。本文档为沉淀后的最终版，覆盖：竞品调研结论、字幕获取策略（B站 dm/view 通道）、YouTube 网络专项、SSE 流式架构、限流设计与踩坑记录。
> 前置文档：`01-需求分析.md`（下载功能）、`02-方案设计.md`（整体架构与抖音通道）。

## 1. 功能概述

解析视频后一键生成 AI 总结，输出四类结构化内容：

- **一句话概述** + **核心要点**（3~6 条）
- **章节大纲**：带时间戳，点击直达视频对应片段（B站/YouTube 拼 `?t=秒`）
- **思维导图**：SVG 横向树渲染，可导出层级数据
- **字幕时间线**：全量字幕按时间排列（为后续字幕提取功能铺路）

交互形态：结果卡内嵌**选项卡面板**（AI 总结 / 字幕时间线 / 思维导图），LLM 输出经 **SSE 流式**实时渲染（打字机效果），完成后切换结构化排版。免费用户按 IP 每日限次（默认 3 次，`AI_DAILY_LIMIT` 可调），超限提示开通会员。

## 2. 竞品调研结论（BibiGPT / Monica / NoteGPT / DLBunny 等）

- 共性流程：链接 → 字幕/转写 → LLM 结构化总结；收费模式均为"每日免费 N 次 + 会员不限次"
- **关键结论**：BibiGPT 不要求用户配置 Cookie 也能拿 B站 AI 字幕——实锤其使用**服务端账号池或自建 ASR**（其界面"字幕识别/重新录制"暗示 ASR 能力）；DLBunny 能下载 YouTube 年龄限制视频，同理是服务端 YouTube Cookie 池
- 差异化启示：时间戳跳转是刚需且成本极低；思维导图用 LLM 返回层级 JSON + 前端 SVG 即可实现，无需引库

## 3. 架构（开闭原则：独立模块追加，不改动旧模块内部）

```
前端 App.vue ──POST /api/summary──▶ main.py ─▶ summarizer.py
     │                                │            ├─ 字幕获取（分平台策略，见 §4）
     │  GET /api/summary/{id}/stream  │            ├─ LLMProvider（OpenAI 兼容流式 / Mock）
     │  （SSE：status→meta→delta*→done/error）     ├─ 输出解析（markdown 分节 + mindmap 围栏）
     └─ GET /api/summary/quota                       ├─ 内存任务表 + 独立线程池(2) + IP 限流
```

关键设计：

- **流式不依赖连接**：素材提取与 LLM 调用都在后台线程执行，增量写入任务的 `stream_buf` 缓冲；SSE 路由只负责搬运。**前端断开/刷新不中断任务**，重连从头重放增量，轮询接口（`GET /api/summary/{id}`）始终可取最终结果
- **LLM 容错**：流式失败自动回退一次性输出；`response_format` 不支持时去字段重试；JSON/markdown 解析三层容错 + 字段默认值
- **输出格式**：LLM 输出 markdown 分节（概述/要点/章节/`mindmap` 代码围栏），服务端解析为结构化 JSON，前端对流式阶段显示原文、done 后结构化渲染
- **任务 TTL 30 分钟**，超时一律清理（防卡死任务泄漏）

## 4. 字幕获取策略（分平台）

### 4.1 B站：dm/view 通道（无需登录、无需签名、无需 Cookie）★核心方案

```text
BV号 --纯本地算法转--> aid（XOR/MASK/ALPHABET 交换表，零网络请求）
x/player/pagelist?bvid=      （免登录）拿 cid
x/v2/dm/view?aid=&oid=cid&type=1   （弹幕池元信息接口，免登录）
  → data.subtitle.subtitles[]  含原生 zh + ai-zh + 多语 AI 翻译
aisubtitle.hdslb.com/...json  字幕直链无需鉴权 → 解析 {body:[{from,content}]}
```

- 语言优先级：原生中文 > AI 中文 > 其它语言
- 该方法参考开源项目 `liyupi/free-video-downloader` 的实现，**完全绕开了需要登录的 player/wbi/v2 接口**（实测 wbi 接口未登录对 8 个热门长视频全部返回空列表，但 dm/view 稳定可用）
- 用户实测：极客湾 Mate 90 评测拿到 371 句字幕（与 BibiGPT 结果一致），总结输出精准章节与时间戳

### 4.2 YouTube：yt-dlp 自动字幕（subtitles/automatic_captions）

- 字幕语言智能排序 `_subtitle_lang_rank`：**中文 > 视频原语言（info.language）> 英文 > 任意轨道**——任何语言都交给 LLM 总结成中文，绝不因语言不匹配漏字幕（修复过日语视频漏字幕的 bug）
- 格式优先 json3 > vtt（时间线信息全），解析为 (纯文本, transcript[{time,text}])，超 12000 字符截断（prompt 声明只总结已有部分）、时间线最多 400 条

### 4.3 抖音：无字幕，降级为标题+简介总结（basis=meta，UI 徽标如实标注）

### 4.4 降级策略

字幕不可用时：标题 + UP主 + 时长 + 简介（B站额外抓取热门评论 `x/v2/reply` 增强，无需登录）；prompt 强制"不得编造视频内容"。降级总结会在 UI 上以橙色徽标"基于视频信息总结"明示，与绿色"基于字幕总结"区分。

## 5. YouTube 网络专项（本功能最大的坑，已全部解决）

| 问题 | 根因 | 解法 |
|---|---|---|
| 解析 502/间歇失败 | WorkBuddy 等终端环境注入的代理环境变量（端口每次会话都变）不可用，而 Python 链路里**环境变量代理优先于注册表系统代理** | 启动时 `os.environ.pop` 清除全部代理环境变量，落到注册表系统代理（用户自己的 Clash，实测 127.0.0.1:5933 可通）；服务器部署用 `backend/proxy.txt` 显式指定 |
| 年龄限制视频被 18+ 墙误拦 | 多 node 共存时取了第一个（node v20），签名求解静默失败 | `_find_node` 扫描全部候选并**按版本取最高**（v22 通过） |
| 真年龄墙视频 | YouTube 强制要求已登录且通过年龄验证的会话，**6 种 player_client（web/tv_embedded/android_vr/ios/mweb/tv）实测全部被拦，无免 Cookie 绕法**（竞品靠服务端 Cookie 池） | **年龄墙定向降级**：命中 `_is_age_gate` 且站长配置了 `cookies/cookies.txt` 时，带 Cookie 定向重试一次；普通视频保持匿名（避免过期访客 Cookie 导致 360p 降级） |
| 字幕内容下载 429 | YouTube timedtext 端点按 IP 限流（测试密集时触发，小时级自动解除） | 3 轮退避重试（3s/6s）；持续 429 时自动降级 meta 总结不报错；正常使用频率不触发 |
| 字幕下载走错网络 | 字幕 CDN 下载的独立 opener 没用上自动探测的系统代理 | opener 链改为：系统代理（`_get_proxy()`）→ 环境默认 → 直连 |

## 6. LLM 接入

- Provider 抽象（借鉴 payments.py 的模式）：`OpenAICompatProvider`（DeepSeek/智谱等 OpenAI 兼容接口，`stream: true` 流式）+ `MockLLMProvider`（本地联调）
- LLM 是国内服务，调用强制直连（`ProxyHandler({})` 绕过系统代理），与字幕网络栈隔离
- 配置（`backend/.env`，参照 `.env.example`）：`LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` / `AI_DAILY_LIMIT`；未配置 key 时接口返回"功能正在开通中"，不影响下载

## 7. API 契约

| 接口 | 说明 |
|---|---|
| `POST /api/summary` `{url, bili_cookie?}` | 支持分享口令；返回 `{task_id}`；400=限流/未配 key/无效链接（可读中文） |
| `GET /api/summary/quota` | `{used, limit, remaining}`；**必须注册在 /{task_id} 之前** |
| `GET /api/summary/{task_id}/stream` | SSE：`status` → `meta` → `delta*` → `done`(结构化结果+transcript) / `error`；断连不丢结果，重连重放 |
| `GET /api/summary/{task_id}` | 轮询兜底（含 404：任务不存在或已过期） |

## 8. 已知限制（截至 2026-10-09 晚）

- YouTube 年龄限制视频：必须配置 cookies.txt（站长级），否则提示不支持——平台政策，无技术绕法
- YouTube timedtext 429：高频使用会临时触发，自动重试+降级兜底，正常频率无感
- 抖音等无字幕平台：降级总结（信息量受限于标题/简介/评论）
- 云沙箱部署：无代理环境，YouTube 不可用（B站/抖音正常）
- 总结结果与字幕时间线 30 分钟后自动清理

## 9. 踩坑记录（精华）

1. **先找参照实现再推演**：B站 字幕连续三轮失败（wbi 签名→SESSDATA→用户 Cookie），直到对照 liyupi 项目源码 5 分钟找到 dm/view 方法。"别人家能做到"时第一动作是抄已验证的答案。
2. **"平台限制"结论要留余地**：B站 字幕有三条接口路径，测了 player/wbi/v2 失败 ≠ 全部不行。
3. **环境代理 vs 系统代理**：Python 链路里环境变量代理优先于注册表代理，WorkBuddy 注入的坏代理会连累一切——显式 pop 环境变量/显式传代理是唯一可靠解。
4. **多 node 共存按版本选**，低版本 node 的签名求解静默失败且报错信息指向别处（年龄墙）。
5. **quota 路由必须注册在 `/{task_id}` 之前**，否则被路径参数吞掉。
6. playwright 调试：eval 多语句必须 IIFE 包裹；ref 跨会话错乱，操作 DOM 用 CSS 选择器；浏览器会话随 shell 结束被杀，全链路测试须单条命令完成。
