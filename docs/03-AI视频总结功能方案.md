## 0. v2 改版记录（2026-10-09 下午，用户反馈驱动）

用户三点反馈：① YouTube 总结失败、B站 总结太简陋，要求"想办法拿字幕，不要总降级"；② 不要弹窗，改为原页内输出 + SSE 流式 + 选项卡（AI 总结/字幕时间线/思维导图）；③ 免费次数要可调（手动测试）。

v2 落地：
- **SSE 流式**：`GET /api/summary/{id}/stream` 推送 `status → meta → delta* → done/error` 事件。素材提取与 LLM 调用都在后台线程执行，SSE 路由只从 `stream_buf` 缓冲搬运增量——**前端断开/刷新不中断任务**，重连从头重放增量。LLM 用 OpenAI 兼容 `stream: true`，流式失败自动回退一次性输出。
- **输出格式改为 markdown 分节**（概述/核心要点/章节大纲/思维导图围栏），服务端解析成结构化 JSON；流式阶段前端直接显示原始文本（打字机效果 + 光标），done 后切结构化渲染。
- **页内选项卡**替代弹窗：📝 AI 总结 / ⏱ 字幕时间线 / 🧠 思维导图。前端 EventSource 监听，连接层错误自动回退轮询。
- **字幕时间线留存**：`_parse_caption` 返回 (纯文本, transcript[{time,text}])，json3/vtt 均带时间戳，最多 400 条，done 事件携带——为后续字幕提取功能铺路。
- **B站降级增强**：抓热门评论（`api.bilibili.com/x/v2/reply`，无需登录）拼入素材，实测总结质量明显改善（能用上"瑞克摇"、高赞评论等信息）。
- **YouTube 年龄门**：新增 `YTDLP_COOKIES_FROM_BROWSER=edge|chrome|firefox` 环境变量，yt-dlp 从本机浏览器读 Cookie（本地部署用；浏览器运行时可能锁库读不到）。
- **AI_DAILY_LIMIT**：`backend/.env` 可调（手动测试调大即可，改完重启）。

v2 已知边界：
- YouTube 能否工作完全取决于部署机代理；沙箱代理到 YouTube 的隧道不稳定（502），代码层无法验证时需在用户本机环境确认。年龄门视频必须配浏览器 Cookie。
- B站 AI 字幕仍需登录 Cookie（SESSDATA）；未登录 + 无 CC 字幕 → 降级（评论增强版）。

## 0.5 v3 字幕攻坚（2026-10-09 傍晚）

用户立场升级："**必须拿到字幕，无论原生还是 AI 字幕**，不许拿降级当偷懒理由"；且网站面向真实用户，**不允许让用户改环境变量**（配置只能是站长级）。

**B站 AI 字幕的硬事实（实测确认）**：
- 裸调 `x/web-interface/view` → 412 风控；随机 buvid3 也过不了
- 视频页 HTML 未登录返回风控验证页（13KB），挖不到 aid/cid
- yt-dlp 未登录同样拿不到 AI 字幕（它内部同样调 wbi 接口，B站不发给未登录请求）
- **结论：AI 字幕是 B站 登录权益，唯一通路 = 服务端配置一个 B站 账号的 SESSDATA**（写进 `cookies/cookies.txt`，站长一次性操作，全站用户零感知，与抖音 ttwid 同设计思想）。CC 字幕（UP主上传的）未登录可拿。

**已实现（summarizer.py）**：
- **B站字幕自研通道** `fetch_bili_subtitles()`：wbi 签名（nav 取 key，mixin 缓存 1h）→ `x/player/wbi/v2` → 字幕直链（aisubtitle.hdslb.com json）→ 解析 `{body:[{from,content}]}` 为时间线。SESSDATA 从 cookies.txt 读取（独立于 yt-dlp 的 enabled 开关）。view 被风控时自动降级从视频页 HTML 提取 aid/cid。
- 优先级链：yt-dlp 字幕（CC/带 Cookie 的 AI）→ **自研 wbi 通道（AI 字幕）** → 降级（标题+简介+热门评论）。
- summarizer 的 yt-dlp 配置与 downloader 对齐：`YTDLP_ENHANCEMENTS`（node JS runtime + ejs 挑战求解）、`proxy.txt` 服务端代理、`socket_timeout=20`（防代理挂起无限卡死）。
- 配套说明：解析接口已被并行工作改为**异步提交+轮询**（POST /api/analyze 返回 analyze_id），"解析卡住"问题在该层解决。

**待验证（依赖用户提供 SESSDATA / 本地环境）**：
1. B站 AI 字幕全链路：拿到 SESSDATA 后写 cookies.txt → 极客湾视频应返回 basis=subtitles + 完整时间线
2. YouTube 全链路：用户本地代理环境（或 backend/proxy.txt 写本地代理）→ 字幕时间线 + 总结

## 1. 需求背景

长视频学习场景下，用户需要快速掌握视频核心内容。作为视频下载网站的附属能力，
"粘贴链接 → AI 总结"能显著提高学习效率，也为网站提供差异化卖点。

**产品决策（已拍板）**：

| 决策点 | 结论 |
|---|---|
| 素材路线 | 字幕优先（yt-dlp subtitles/automatic_captions），拿不到字幕降级为「标题+简介」总结，UI 徽标如实标注依据；ASR 转写留待下一期 |
| LLM 渠道 | 用户提供 API key（DeepSeek / 智谱 GLM 等 OpenAI 兼容接口），环境变量配置；Provider 抽象可随时换渠道 |
| 输出形态 | 一句话概述 + 核心要点 + 章节大纲（时间戳可跳转）+ 思维导图（SVG 渲染） |
| 免费额度 | 按 IP 每日 3 次（内存计数），超限提示开通会员；会员门禁本身仍是 P2（无用户系统） |

## 2. 竞品调研摘要

调研对象：BibiGPT、Monica、NoteGPT、通义听悟、AI课代表 等（2026-10）。

**共性流程**：粘贴链接 → 提取字幕/语音转写 → LLM 生成结构化内容（摘要/章节/导图/AI 追问）。

**收费模式共性**：每日免费 N 次 + 时长上限（如 BibiGPT 免费 3 次/天、30 分钟上限；AI课代表 3 次/天），会员解锁更多次数与高级模型。我们的 3 次/天限流策略与市场一致。

**差异化启示**：
- 有字幕平台体验远好于无字幕平台；无字幕时 ASR 是刚需（我们本期用"降级+如实标注"过渡）
- 时间戳跳转是长视频学习的高频刚需，成本极低，必须做
- 思维导图是竞品标配亮点，LLM 直接返回层级 JSON + 前端 SVG 渲染即可实现，无需引库

## 3. 技术方案

### 3.1 架构（遵守开闭原则：纯追加，不动旧模块）

```
前端 App.vue ──POST /api/summary──▶ main.py ─▶ summarizer.py
     │                                │            ├─ 字幕提取（yt-dlp extract_info，不下载）
     │  GET /api/summary/{id} 轮询 ◀──┘            ├─ 降级素材（抖音走 douyin.py 现有解析）
     │                                             ├─ LLMProvider（OpenAI 兼容 / Mock）
     └─ GET /api/summary/quota 查剩余次数            ├─ JSON 容错解析
                                                   └─ 内存任务表 + 独立线程池(2) + IP限流
```

- 新增 `backend/app/summarizer.py`（独立模块，只 import 复用 `douyin`/`downloader._apply_cookies`，不修改它们）
- `main.py` 在支付路由后集中追加 3 条路由；`startup` 清理协程追加 `summarizer.cleanup_expired()`
- 前端 `MindMap.vue` 新组件；`App.vue` 以新增区块/watch 追加接入

### 3.2 关键设计

**素材组装 `_build_material(url) → (text, basis, meta)`**
- 抖音：复用 `douyin.analyze()` 取标题/简介/作者 → basis=meta
- 其它平台：yt-dlp `extract_info(download=False)`：
  - `subtitles`（手动）优先于 `automatic_captions`（自动）；语言优先序 zh-Hans/zh-CN/zh/ai-zh/en，格式优先 json3/vtt
  - 字幕 >50 字 → basis=subtitles（超 12000 字符前缀截断，prompt 声明只总结已有部分）
  - 否则降级：标题+UP主+时长+简介(≤2000字) → basis=meta

**Prompt 与输出约束**：system 强制仅输出 JSON
`{summary(≤80字), points(3~6条), chapters[{time,title,detail}], mindmap{title,children[] ≤3层每层≤5节点}}`；
无时间信息 chapters=[]；meta 降级时输出精简版且不得编造。

**JSON 三层容错**：剥 ```json 围栏 → 截取首{到末} → json.loads 失败让 LLM 重试一次 → 最终兜底把原文当概述；字段级校验+默认值，前端对 mindmap/chapters 空值整块隐藏。

**LLM 调用**：标准库 urllib（零新增依赖）+ `ProxyHandler({})` 强制直连（LLM 是国内域名，绕开系统代理坑）；`response_format: json_object`，4xx 报 response_format 相关错误时自动去字段重试；网络/5xx 重试 1 次；timeout 90s。

**任务与限流**：
- 独立 `ThreadPoolExecutor(max_workers=2)`，不挤占下载的 3 workers
- 状态机：`fetching_subtitles → summarizing → done/error`；task_id=uuid hex[:12]
- 结果 TTL 30 分钟，挂进 main.py 现有 600s 清理协程
- IP 限流：`_quota[ip] = {date, count}`，日期翻转自动重置；IP 取 `X-Forwarded-For` 优先（云沙箱在反代后）

### 3.3 API 契约

| 接口 | 说明 |
|---|---|
| `POST /api/summary` `{url}` | 支持分享口令；返回 `{task_id}`；400=限流/未配 key/无效链接（可读中文） |
| `GET /api/summary/quota` | `{used, limit, remaining}`；**必须注册在 /{task_id} 之前**，否则 "quota" 被当 task_id 吞掉 |
| `GET /api/summary/{task_id}` | 轮询；done 返回 `{basis, title, webpage_url, duration, platform, result{...}}` |

### 3.4 前端交互

- 解析结果卡新增 ai-row：「✨ AI 总结」按钮（两阶段 loading：正在提取字幕… / AI 总结中…，120s 超时兜底）+ 今日免费 x/3 次
- done 自动弹窗：标题 + 依据徽标（绿=基于字幕 / 橙=基于视频信息，附 tooltip 说明）+ 概述 + 要点 + 章节行（时间戳 chip，B站/YouTube 拼 `?t=秒` 直达，抖音跳原链接）+ MindMap + 复制全文
- 接入方式：`watch(info)` 联动清理与拉取配额，未改动 analyze/reset 原有逻辑

## 5. 踩坑与已知限制

1. **B站 AI 字幕（ai-zh）需要登录态 Cookie**：未登录时 player API 不返回字幕轨道，实测热门榜 6 个视频全部无字幕。`backend/cookies/cookies.txt` 目前无 SESSDATA → B站大概率走降级总结。想让 B站 出全量总结，需要站长更新有效 Cookie。
2. **旧服务进程占端口**：测试时 8000 被上个会话遗留的 uvicorn 占用（10048），新路由"不生效"其实是打到旧进程。`netstat -ano | grep :8000` 先查再杀。
3. **playwright 浏览器会话随 shell 结束被杀**：每条命令都是新 shell，必须把 open→操作→断言 串进**同一条命令**执行。
4. **quota 路由顺序**：`GET /api/summary/quota` 若注册在 `/{task_id}` 之后会被路径参数吞掉，返回 404。
5. **XFF 可伪造**：免费额度场景损失可控，接受（与内存任务表同风险级别）；接用户系统后改账号级限流。
6. YouTube 字幕/总结依赖本地代理（用户承诺保持开启）；云沙箱内 B站/YouTube 受限，线上以抖音降级链路为主。
