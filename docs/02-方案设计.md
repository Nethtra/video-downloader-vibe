## 1. 总体架构

```
                        ┌──────────────────────────────────────────────┐
   浏览器 SPA           │            FastAPI 单进程（:8000）            │
  Vue 3 + Vite  ───────▶│                                              │
  构建产物由后端托管      │  /api/analyze   ─┐                           │
                        │  /api/download  ─┼─▶ downloader（任务表+线程池）│──▶ yt-dlp
                        │  /api/task /file ┘        │                   │      │
                        │                           └─ 抖音分支 ─────────│──▶ douyin.py（自研）
                        │  /api/summary + SSE ─▶ summarizer ────────────│──▶ 字幕通道
                        │        │                    │                │──▶ LLM（流式）
                        │        └─ 结果 TTL 30min      └─ 分块摘要       │
                        │  /api/auth/*  ─▶ auth.py ─▶ db.py（SQLite）    │
                        │  /api/pay/*   ─▶ payments.py（Stripe/Mock）    │
                        │  /robots.txt /sitemap.xml /llms.txt ─▶ seo.py │
                        │  /{path}（SPA 兜底 + SEO 注入）                │
                        └──────────────────────────────────────────────┘
                                        │
                              backend/data/app.db
                       users / sessions / orders / webhook_events
```

- **单服务单端口**：前端产物放 `backend/static`，FastAPI 一并托管；部署只有一个 Python 进程
- **任务在内存**：解析 / 下载 / 总结任务都是进程内字典 + 线程池，30 分钟 TTL 清理
- **持久化只存账号与交易**：SQLite（标准库 `sqlite3`，WAL），不存下载历史
- **单 worker 约束**：内存任务表决定了不能多进程启动；`run.py` 固定单进程 uvicorn

## 2. 技术选型

| 层 | 选型 | 为什么 |
|---|---|---|
| 后端 | Python 3.10+ / FastAPI + Uvicorn | yt-dlp 是 Python 库，直调可拿 `progress_hooks`、结构化异常，零跨语言开销 |
| 下载 | yt-dlp + ffmpeg | 1000+ 平台由社区维护；ffmpeg 负责 DASH 音视频合并与音频提取（缺失时降级渐进式格式） |
| 前端 | Vue 3 + Vite 8（rolldown） | 需求方指定 Vue；构建产物是纯静态文件，不增加部署复杂度；不引 UI 框架 |
| 样式 | 原生 CSS + CSS 变量 | 设计系统集中在一处；避免引入 Tailwind/组件库带来的体积与审美约束 |
| 数据 | SQLite（`db.py`） | 只有账号/会话/订单需要持久化，标准库即可，不引入 MySQL/Redis |
| 支付 | `PaymentProvider` 抽象 + Stripe Checkout | 无密钥自动回退 Mock；接新渠道只需新增 Provider |
| AI | OpenAI 兼容 Provider（DeepSeek / 智谱） | 国内直连、支持流式；可替换模型 |
| 实时输出 | SSE | 单向推送够用，比 WebSocket 轻；断线由前端轮询兜底 |
| 国际化 | 自研扁平字典（`i18n.js`） | 6 语言、零依赖、无构建期提取 |
| SEO | 运行时注入（`seo.py`） | 单页无路由，注入与预渲染等价；不碰 vite 构建链 |

## 3. 核心流程

### 3.1 解析 → 下载

```
用户            前端                    后端                      引擎
 │ 粘贴链接 ────▶ POST /api/analyze ───▶ 创建 analyze 任务（线程池）
 │              轮询 /api/analyze/{id} ◀─ running / done(info) / error
 │ 选清晰度 ────▶ POST /api/download ──▶ 创建下载任务（服务端做会员门禁）
 │              轮询 /api/task/{id}   ◀─ downloading / processing / done
 │ 点保存 ──────▶ GET /api/file/{id}  ◀─ FileResponse（30 分钟内有效）
```

- 解析异步化：YouTube 等平台可能耗时数十秒，同步等待会被网关 504 掐断
- 清晰度归一：后端把原始 format 列表按分辨率分组取最优，前端只显示 `1080p / 720p / 仅音频`
- 会员门禁：`download` 路由根据登录态传 `max_height=1080`，**在服务端替换 fmt 表达式**，不信任前端参数

### 3.2 下载任务状态机

```
downloading ──▶ processing（DASH 合并，仅 yt-dlp 路径）──▶ done
      └────────────────────────────────────────────────▶ error
done / error 的任务与文件 30 分钟后清理
```

### 3.3 平台分流

| 入口 | 走向 |
|---|---|
| 抖音 URL / 口令 | `douyin.py` 自研通道（ttwid + iesdouyin 分享页），下载走独立流式分支 |
| B站 AI 总结 | `summarizer.py` 的 `dm/view` 字幕通道（不经 yt-dlp） |
| B站 下载 | 目前 yt-dlp；云 IP 受限，自研通道方案见 `09-B站直连通道方案.md`（搁置） |
| 其它平台 | yt-dlp |

## 4. 关键模块与边界

| 模块 | 职责 | 不负责 |
|---|---|---|
| `downloader.py` | URL 分流、解析/下载任务表、清晰度归一、ffmpeg 合并、TTL 清理、代理探测 | 平台特定的签名/风控 |
| `douyin.py` | 铸 ttwid、解析分享页、无水印直链、流式读取 | 图集/图文（明确报错） |
| `summarizer.py` | 字幕获取（B站/YouTube）、长视频分块、LLM 调用、SSE 缓冲、IP 限流 | 下载；字幕翻译 |
| `auth.py` / `db.py` | 注册登录、scrypt、Cookie 会话、会员判定、订单/去重表 | 找回密码 / 邮箱验证（未做） |
| `payments.py` | 套餐定义、Stripe Checkout、webhook 验签、统一履约、Mock 回退 | 订阅续费 / 退款自动撤权 |
| `seo.py` | 注入 title/description/canonical/OG/JSON-LD、静态正文、robots/sitemap/llms | 多路由落地页（未做） |
| `main.py` | 路由编排、静态托管、SPA 兜底、异常转中文、定时清理 | 业务逻辑 |

### 4.1 抖音免 Cookie 通道（`douyin.py`）

```
① 铸造访客凭证：POST ttwid.bytedance.com/ttwid/union/register/
   （字节官方接口，返回 Set-Cookie ttwid；系统自铸、不含用户身份，进程内存缓存 5 天）
② 匿名解析：GET www.iesdouyin.com/share/video/{id}
   （移动端 UA + ttwid → SSR 页面内嵌 window._ROUTER_DATA）
③ 无水印直链：play_addr.url_list 的 /playwm/ → /play/
   （HD 档：iesdouyin.com/aweme/v1/play/?video_id={uri}&ratio=1080p&line=0）
```

- ID 提取覆盖：`/video/{id}`、`/note/{id}`、任意路径 `?modal_id=`、`v.douyin.com` 短链（读重定向）、分享口令文本
- 网络层强制直连（`ProxyHandler({})`），避免宿主机代理导致间歇性连接失败
- 图集/图文明确报错，不静默失败

## 5. 数据与状态

**SQLite（`backend/data/app.db`，gitignore）**

| 表 | 用途 |
|---|---|
| `users` | email、scrypt 密码哈希、`vip_until` |
| `sessions` | 会话 token、user_id、过期时间（30 天，定时清理） |

**内存任务（重启即丢，属设计取舍）**

| 任务 | TTL |
|---|---|
| 解析任务 | 10 分钟 |
| 下载任务 / 文件 | 30 分钟 |
| AI 总结任务 / 结果 | 30 分钟 |

## 6. 部署形态

| 环境 | 方式 | 说明 |
|---|---|---|
| 本地开发 | `python run.py`（8000）+ `npm run dev`（5173 代理 `/api`） | 日常开发 |
| 本地生产 | `npm run build` 后只跑 `python run.py` | 单端口全功能 |
| 自有服务器（当前线上） | 宝塔 Python 项目 + Nginx 反代 + HTTPS | 阿里云香港轻量；域名由站长在 `SITE_URL` 中自行配置 |
| WorkBuddy 沙箱（历史） | 平台自动部署 | 早期预览用，已被自有服务器取代 |

**部署硬约束**：单进程、单端口；Nginx 必须关闭 `proxy_buffering` 并把读超时调到 1200s，否则 SSE 会攒包或中断。
完整步骤见 `08-宝塔部署指南.md`。
