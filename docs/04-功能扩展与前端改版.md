## 1. AI 总结功能扩展

### 1.1 思维导图：全屏 + 导出
- `MindMap.vue` 增加工具条（全屏 / PNG / SVG）；覆盖层全屏支持「适应窗口 ↔ 原始大小」切换、ESC 关闭；全屏模式布局参数放大、标题截断放宽到 14 字
- 导出全部在浏览器本地完成：SVG 用内联样式构造独立字符串（白底）；PNG 经 Image + Canvas 2 倍缩放转换。不加后端接口
- **踩坑（vite 8 / rolldown CSS 裁剪）**：只出现在动态 `:class` 三元表达式里的 CSS 类会被当 unused 静默裁掉（`.mm-node` 等消失 → 导图全黑）。对策：SVG 颜色改内联 `:style` 绑定（带 `var()` 回退）；构建后 grep 产物 CSS 验证关键规则
- **踩坑（树布局 id 分配）**：递归建树时 `id = nodes.length` 必须配合「先 push 占位再递归」，否则子节点先占坑导致 id 重复、连线端点映射错乱（节点位置全对但线缺失，单子节点分支必现）

### 1.2 字幕文件下载（SRT / TXT）
- 「字幕时间线」页签提供「下载 SRT / 下载 TXT」；从已解析的时间线在前端本地生成，零后端
- SRT：起始时间为该句时间戳，结束时间取下一句开始（最后一句 +2s 兜底）；文件名取视频标题（过滤非法文件名字符）

### 1.3 移除 B站 SESSDATA Cookie 功能
- dm/view 字幕通道免登录免 Cookie 后，「字幕设置」按钮及后端 `bili_cookie` 参数链（main.py SummaryReq → summarizer.start_summary → _build_material → fetch_bili_*）全部删除
- 前端顺手 `localStorage.removeItem('bili_sessdata')` 清理老用户浏览器遗留

## 2. AI 总结质量调优

### 2.1 详细度
- 概述：1 句 80 字 → 2~3 句 150 字（必须带核心结论）
- 要点：3~6 条 × 40 字 → 5~8 条 × 40~120 字（要求具体到方法/数字/技术名词/因果）
- 章节：3~8 个一句话 → 4~10 个每章 2~3 句
- 解析端截断兜底（要点 [:220]、章节说明 [:300]）要设得比 prompt 上限宽——LLM 实际输出经常超出 prompt 限制，硬截断产生断尾句子
- 字幕素材预算 12000 → 16000 字符

### 2.2 章节时间真实性
- **素材必须带时间戳**：`_timed_text()` 把时间线渲染为每行 `[分:秒] 原文` 的格式再喂给 LLM，并在 prompt 中要求章节时间取素材真实时间戳。否则 LLM 只能按内容比例估算，输出全是整数分钟
- 效果：章节时间从 `1:30/5:00/8:00` 变为 `2:10/5:19/7:56` 级别的真实值

### 2.3 章节行解析鲁棒性
- LLM 章节行格式存在随机变体，`_CHAPTER_LINE` 已全兼容：`**` 加粗有无、时间戳「约/大约」前缀、时间区间 `[00:00-03:10]`（取起点）、全角冒号、标题/说明分隔符全/半角
- 要点/章节标题中的 markdown 加粗标记（`**`）统一剥除，避免前端裸露星号
- **方法论**：LLM 输出解析类 bug 必须拿**真实 raw 输出**复现（diag 脚本绕过 quota 直接调 provider）；"换个视频正常"不代表没问题。raw 样本可留存做离线回归

## 4. 国际化（i18n）

- 新增 `frontend/src/i18n.js`：零依赖方案（reactive locale + 扁平字典 + `t(key, params)` 字符串插值 / `tl(key)` 数组词条）
- 语言：简体中文（默认）+ English / 日本語 / 한국어 / Español / Français；导航栏右侧下拉切换
- 首次访问按 `navigator.language` 自动选择，手动切换持久化 localStorage；缺失 key 回退 zh-CN
- 覆盖范围：全站 UI 文案 + 错误提示 + 支付弹窗 + 思维导图组件按钮
- **后端 `/api/plans` 仍返回中文**：前端 `plansView` computed 按 `plan.id` 用字典覆盖 name/period/features，缺失回退后端原文，后端零改动
- 实现注意：法语字典的直撇号（`n'ajoutons`）会破坏 JS 单引号字符串 → 用弯撇号 `’`；字幕时间线循环变量避免命名 `t`（遮蔽翻译函数）

## 5. 线上部署与平台现状

### 5.1 部署问题修复
- **winreg 崩溃（本轮修复）**：`_get_proxy()` 读 Windows 注册表探测系统代理，`import winreg` 在 Linux 沙箱抛 `ImportError`（非 OSError）穿透 except → 线上所有解析报 `No module named 'winreg'`。已改为 `except Exception` 静默跳过。教训：跨平台代码的异常捕获要按"实际会抛什么"而非"想象中的类型"
