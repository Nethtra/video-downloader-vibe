## 版本 A：完整版（适合项目经历栏空间充足）

**极易下 — 万能视频下载与 AI 内容总结平台**（个人全栈项目）
技术栈：Vue 3 + Vite / FastAPI + yt-dlp / SQLite / Stripe / DeepSeek（OpenAI 兼容 LLM）/ SSE

- 独立设计并开发「视频解析下载 + AI 总结」一体化 Web 平台，支持抖音、B站、YouTube 等多平台视频解析下载，集成基于大模型的视频内容总结、字幕时间线与思维导图生成，对标 BibiGPT/Monica 产品形态。
- 设计多通道视频解析架构：针对 B站字幕获取，逆向分析平台接口，实现 BV→aid 纯算法转换 + 弹幕池接口取字幕列表的免登录方案，绕过官方签名与 Cookie 校验；针对 YouTube 处理 DASH 音视频流合并、签名解析与多客户端降级重试。
- 实现基于 SSE 的流式 LLM 输出管道：后台线程调用 LLM 增量写入缓冲，前端 EventSource 实时渲染，断线刷新不丢结果；设计三层容错与解析端兜底截断，保证 LLM 非结构化输出的稳定解析。
- 设计工程化的解析容错体系：字幕语言智能排序（支持任意语言视频总结）、IP 级每日限流、任务内存化 + TTL 过期、代理环境自适应（系统代理/环境变量/直连多级回退）。
- 实现完整支付与会员系统：SQLite 数据持久化、邮箱密码认证（scrypt 哈希 + HttpOnly Cookie）、Stripe Checkout 支付、三层幂等防护（幂等键/事件去重表/订单状态机）、会员权益门禁（清晰度限制、AI 总结不限次）。
- 落地 SEO/GEO 优化：后端运行时注入完整 SEO 标签与 JSON-LD 结构化数据（含 FAQPage/HowTo），提供 llms.txt 与 robots 爬虫策略，提升搜索引擎与 AI 引擎可检索性；实现 6 语言国际化（零依赖自研 i18n 方案）与深色模式三态切换。

## 面试可能的追问点（自备，不写进简历）

1. **B站字幕通道**：为什么不用 player/wbi/v2？（需登录态，未登录永远空列表）dm/view 接口为何可行？（弹幕池元数据接口不校验登录）
2. **SSE vs WebSocket**：单向推送够用，SSE 更轻、自带重连语义；LLM 在后台线程跑、只把增量搬进 stream_buf，断连/刷新从缓存续读。
3. **幂等三层**：前端幂等键防重复提交 → webhook event 去重表防 Stripe 重发 → 订单状态机原子流转兜底。
4. **LLM 输出解析鲁棒性**：真实 bad case 回归（保存 raw 样本离线测试）、prompt 与解析端双重约束、解析截断阈值宽于 prompt 上限。
5. **跨平台/环境坑**：Windows 注册表代理 vs Linux 沙箱、依赖运行时版本探测取最高——体现"我测过 ≠ 用户能跑"的工程意识。
